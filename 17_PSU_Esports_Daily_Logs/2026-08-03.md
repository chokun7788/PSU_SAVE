## Research Note - Anti-Hallucination / Capability Selection / Route-Answer Check

### วิเคราะห์ปัญหา

- ปัญหาหลักของ chatbot ตอนนี้ไม่ใช่แค่ LLM แต่งข้อมูล แต่รวมถึง route/tool/target ผิดแล้วคำตอบหลุดออกไป
- กลุ่มปัญหาที่ต้องแก้ก่อน queue:
  - Answer Contract / Anti-Hallucination
  - Capability Selection v2
  - Route-Answer Cross-check
- ลักษณะปัญหา:
  - ถามปุ่ม แต่ตอบวิธีเล่นหรือรายละเอียดเกม
  - ถามราคา แต่ตอบ catalog เกม
  - target เกมคลุมเครือแล้วเลือกเกมผิด
  - follow-up สั้น ๆ เช่น `ปุ่ม` อาจไม่ผูก context เดิม
  - ข้อมูลไม่มี แต่ระบบยังพยายามหา answer path อื่น

### Paper/เทคนิคที่เกี่ยวข้อง

- Self-RAG: adaptive retrieve/generate/critique
- CRAG: retrieval evaluator ก่อน generation
- RARR: research-and-revision หลัง generate เพื่อตรวจ attribution
- SelfCheckGPT / FactSelfCheck: consistency-based hallucination check
- SummaC / QAGS: factual consistency check ระหว่าง answer กับ evidence
- Gorilla/APIBench: retrieval-aware tool/API selection ลด tool hallucination
- Selective Classification / Calibrated Selective Classification: abstain เมื่อ confidence ไม่พอ
- Semantic Router / LLM routing papers: candidate routing + cost/accuracy-aware selection

### ข้อเสนอเชิงระบบ

- ทำ `Answer Contract` ต่อ capability ทุกตัว
- ทำ `Capability Candidate Ranking` ให้ route ไม่ใช่เลือกทางเดียวทันที
- ทำ `Evidence/Source Alignment` ก่อนปล่อยคำตอบ โดยเฉพาะราคา ปุ่ม เกม เครื่อง และสมาชิก
- เพิ่ม `Abstain / Clarify` เมื่อ margin ต่ำหรือ evidence ไม่พอ
- ทำ focused eval จาก bad cases จริงก่อนค่อยทำ queue
