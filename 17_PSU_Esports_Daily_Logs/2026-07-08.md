## Accuracy-First Hybrid Pipeline

ผู้ใช้ขอให้ทำแบบที่ได้คำตอบดีที่สุด โดยส่งผลเสียน้อยที่สุด และยังรักษาลักษณะคำตอบเดิม

สิ่งที่ตอบ/ยืนยันก่อนทำ:

- vector index ตอนนี้มี 278 docs
- เป็นข้อมูล curated หลักทั้งหมดที่ `load_curated_rows()` โหลด ไม่ใช่ข้อมูลทุกไฟล์ทั้งระบบ
- ข้อมูลจาก Our Games ที่ scrape มาแล้วเข้า vector index แล้ว
- calendar/holiday, rule patterns, raw sources, test/ground truth และ fast path logic ยังไม่ได้เข้า vector โดยตรง

ไฟล์ pipeline spec:

- `docs/20_accuracy_first_hybrid_pipeline.md`
  - อธิบาย pipeline แบบละเอียด
  - กำหนดลำดับ `deterministic fast path -> hybrid candidate retrieval -> rerank -> evidence guard -> formatter`
  - ระบุแนวทาง Vercel-safe: ยังไม่โหลด neural embedding model ตอน runtime
  - วางแผน offline neural embedding ในระยะถัดไป

สิ่งที่ implement:

- เพิ่ม `app/pipeline/hybrid_retrieval.py`
  - รวม candidate จาก lexical curated retrieval และ guarded vector retrieval
  - rerank ใหม่ด้วย category/entity/source/vector/lexical/priority
