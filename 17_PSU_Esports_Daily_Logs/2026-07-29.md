# PSU Esports Daily Log - 2026-07-29

## Latest Update - compound question planner and answer validation hardening

### เพิ่มล่าสุดรอบคำถามหลายส่วน/route ผิดเจตนา

- แก้ Compound Question Planner ให้แยกคำถามที่เปลี่ยน subject กลางประโยคได้ถูกขึ้น เช่น `Tekken 8 ปุ่มอะไร แล้ว PC ราคาเท่าไหร่` ไม่ลาก `Tekken 8` ไปตอบราคาแทน `PC`
- เพิ่มให้ splitter เข้าใจคำว่า `กับ` ในบริบท shared-subject operation เช่น `PS5 มีเกมอะไรกับราคาเท่าไหร่` แยกเป็น `PS5 มีเกมอะไร` และ `PS5 ราคาเท่าไหร่`
- แก้ logic คำว่า `เล่นยังไง` ให้ถ้าเกมมี `วิธีเล่นโดยสรุป` ให้ตอบเป็น game detail ก่อน ไม่ดึงปุ่มมาแทน แต่ถ้าเกมไม่มีสรุปวิธีเล่นและมีข้อมูลปุ่มจริง เช่น `Mario Kart Live เล่นยังไง` ยัง fallback ไปตอบปุ่มได้
- เพิ่ม `source_type=control_game` ให้ structured game control hits เพื่อให้ source trace/audit แยกได้ว่าคำตอบปุ่มมาจาก control data จริง
- ปรับ real usage golden eval ให้อ่าน `source_type` ตอนตรวจ source contract เพื่อไม่พลาดหลักฐานที่อยู่ใน metadata
- เพิ่ม `tools/validate_compound_questions.py` สำหรับ regression คำถามหลายส่วน 7 เคส ครอบคลุมหลายเกม, เกม+ราคา, เกม+จอง, จอง+ราคา และ explicit new subject
- รัน full regression แล้วผ่าน 24/24 cases, compound validation ผ่าน 7/7 และ game control validation ผ่าน

### ใช้เทคนิค/วิธีไหนรอบนี้

- Shared-subject operation splitting พร้อม connector handling
