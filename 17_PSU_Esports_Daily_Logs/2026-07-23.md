## Adaptive Intent LLM Default

- ปรับ pipeline ให้เมื่อ `experimental_allow_llm=True` จะเปิด adaptive Intent LLM review เป็นค่าเริ่มต้นหลัง normalize/candidate routing
- ยังไม่ให้ LLM เป็นด่านแรกสุด:

- เพิ่ม `intent_candidates` ลง trace ของ `universal_intent` เพื่อ debug ได้ว่า LLM เลือกจาก candidate ไหน

## Intent Gate Guard Implementation

- เพิ่ม guard ชุดเล็กสำหรับลดปัญหา heuristic มั่นใจผิดแล้วข้าม Intent LLM:
  - เพิ่ม risk flags ใน `universal_intent.py`
  - เพิ่ม clear platform game catalog gate เช่น `PS5 มีเกมอะไรบ้าง` ให้ข้าม Intent LLM ได้เมื่อ route ชัด
  - เพิ่ม competition route override ให้ `ROV รอบชิงเล่นกี่เกม` เป็น `competition_rules/rule_lookup`
  - ลด game catalog override เมื่อคำถามมี people/role signal เช่น `สตาฟ`, `ตำแหน่ง`, `ใคร`
  - เพิ่ม member route override ให้ `overview/members_lookup` ที่ operation ยังไม่ชัด กลายเป็น `members/list`
- เพิ่ม precondition/veto:
  - people/role query map ไป `structured.members`
  - reject `structured.games` และ game fast handler เมื่อคำถามเป็น people/role query
- เพิ่ม answer validator:
  - reject คำถาม people/role ที่ตอบเป็น game catalog
- เพิ่ม regression cases:
  - `ROV รอบชิงเล่นกี่เกม`
  - `PS5 มีเกมอะไรบ้าง`
