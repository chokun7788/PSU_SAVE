### ปัญหาและ root cause

1. ตัวแปร `rag_llm_attempted`/`rag_source_conflict` ไม่ถูก initialize ทุก branch ทำให้เกิด `UnboundLocalError` ในรอบเดิม
2. คำว่า `เสีย` ถูกใช้เป็น price substring ทำให้ `ข้อเสีย` route ไป Service Fee
3. คำถามนิยาม mechanical keyboard ถูกคำนาม equipment กลบ operation definition
4. ASCII alias `cross` match อยู่กลางชื่อ `Animal Crossing`
5. คำถาม ranking เกมตามโซนถูกคำว่าเครื่อง/โซนดึงไป Equipment หรือ LLM
6. คำถามข่าว/เพลง/ข้อมูลล่าสุดไม่มี live source แต่ General LLM อาจตอบจาก model memory
7. Clear General ใช้ Intent LLM และ General LLM ต่อกัน ทำให้ 41 cases เดิมเฉลี่ย 14.7497 วินาที
8. `num_predict` แบบเดียวทุกคำถามทำให้คำตอบสั้นแพงเกินไปหรือ tradeoff ถูกตัดก่อนครบ
9. Planner timeout เคยเปิด model-wide circuit แล้วปิด General answer ทั้งกลุ่ม เพราะ health state ไม่แยก optional call kind
10. Failure ที่ห่างกันหลายนาทีถูกนับต่อเนื่อง เพราะไม่มี rolling failure window
11. Reservation/service catalog ที่ไม่มี specific game ยัง fuzzy scan aliases ทุกเกม ทำให้ structured path ใช้ 5-7 วินาที
12. Compound comparison ถูกจัดเป็น dependency complex และ shared booking tail ถูก propagate ผิด semantics
13. Bare `ร่างกาย` ชน text-generation keyword `ร่าง`; bare `เกม`/`จอง` เสีย optional LLM/RAG call
14. Affected-scope v1 พบ compound Cockpit ราคา+จอง 3 timeout: service availability เปิด fuzzy game scan จาก booking signal แม้ target เป็น zone และ reservation fact fuzzy ทุก alias แม้มี exact `จองยังไง`
