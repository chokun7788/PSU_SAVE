## Latest Update - Chatbot-focused Technical Poster

### สรุปสิ่งที่ทำ

- ออกแบบโปสเตอร์ A3 แนวนอน เน้น FAQ Chatbot และแสดง End-to-End Flow ตั้งแต่ Web Chat จนถึง Final Answer
- แสดงบทบาท Fast/Structured, Semantic RAG, Safe Outcome และ Gated Local LLM ให้ไม่สับสนกัน
- เพิ่ม Benchmark ปัจจุบัน สถานะ Core Functions และงานที่ต้องทำต่อก่อนเป็น Product
- ส่งออกทั้ง PNG ความละเอียดสูงและ PowerPoint ที่แก้ไขต่อได้

### ปัญหาและ Root Cause

- Flow แบบย่อก่อนหน้านี้วาง Local LLM Assist ในตำแหน่งเดียวกับ Execution Path ทำให้ดูเหมือนมาแทน Safe Outcome
- Root cause คือการย่อ Flow มากเกินไปจนผสมระหว่าง "เส้นทางหาคำตอบ" กับ "ผู้ช่วยแบบ gated"
- ในโปสเตอร์ใหม่จึงคง Execution Paths เป็น Fast/Structured, Semantic RAG และ Safe Outcome ส่วน Local LLM แยกเป็น optional assist หลัง Evidence/Draft และใช้ช่วย Intent/Planner/Router/Composer ตามเงื่อนไข

### สิ่งที่เพิ่มหรือแก้

- เพิ่ม Flow: Web Chat/API -> Context/Split -> Understand -> Score/Preconditions -> Execution Paths -> Evidence/Draft -> Optional Local LLM -> Validation/Repair/Veto -> Final Answer
- เพิ่มคำอธิบาย Semantic RAG: BGE Embedding -> Retrieval -> Optional Rerank -> Evidence -> Draft
- เพิ่ม Answer Safety: Boundary/Ambiguity Gate, Source Guard, Answer Contract, Bounded Repair และ Hard Veto
- เพิ่มข้อจำกัด Local LLM: สูงสุด 2 calls/request และ concurrency 1
- เพิ่มสถานะ Core Functions: FAQ Ready, Check Slot Waiting WP API, Admin Input Designed และ Booking Future

### เทคนิคและวิธีที่ใช้

- สร้างโปสเตอร์เป็นวัตถุ PowerPoint เพื่อรักษาความคมของข้อความไทยและแก้ไขต่อได้
- ใช้ภาพประกอบ AI แบบไม่มีข้อความเป็น supporting visual; ข้อความและแผนภาพทั้งหมดจัดวางแบบ deterministic
- ใช้ connector แยกสีตาม Path และแสดง Safe Outcome เป็นเส้นทางจริง ไม่ใช่ Local LLM fallback
