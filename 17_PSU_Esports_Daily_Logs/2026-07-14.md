## Minecraft / Game Data Availability Timeout Fix
- Production query `เกม Minecraft มีข้อมูลไหม` returned Vercel 504 `FUNCTION_INVOCATION_TIMEOUT`.
- Root cause: phrase `มีข้อมูลไหม` was not classified as game availability, so unknown named games could fall through to heavier RAG/experimental fallback.
- Added deterministic game availability handling:
  - `มีข้อมูลไหม`, `ข้อมูลไหม`, `อยู่ในฐานข้อมูลไหม` now route as game availability.
  - Added explicit known-unsupported aliases for Minecraft and Roblox.
  - `เกม Minecraft มีข้อมูลไหม` now returns `games_known_unsupported_fast_path`.
  - `เกม TEKKEN 8 มีข้อมูลไหม` returns `games_availability_fast_path`.
- Disabled frontend `experimentalAllowLlm` for Vercel usage.
- Added API guard so Vercel only honors LLM fallback when `PSU_VERCEL_ALLOW_LLM=1`.
- Updated game catalog smoke tests for Minecraft unsupported and TEKKEN availability cases.
