## Vercel API 504 / Non-JSON Error Investigation
- ผู้ใช้เจอ frontend error: `Unexpected token 'A', "An error o"... is not valid JSON`
- สาเหตุคือ frontend เรียก `response.json()` แต่ Vercel ส่ง plain text error/504 กลับมา ไม่ใช่ JSON
- ตรวจ production พบ `PS5 มีเกมอะไรบ้าง` ได้ 504
- แก้ performance ของ query variants:
  - ไม่ให้ `normalize_text()` ยัด keyboard-layout garbage เข้า normalized query ทั่วไป
  - ให้ `build_query_variants()` สร้าง variant เฉพาะเมื่อ keyboard conversion เจอ signal ใหม่จริง
  - กรณี `ทนิฟ -> moba` ใช้ variant แบบ `คำถามเดิม + moba` แทนการใช้ประโยคที่ถูกแปลงทั้งประโยคจนเพี้ยน
  - ปรับ selector ให้ keyword genre จาก variant ชนะ generic `games_lookup`
- เพิ่ม Postgres connect timeout สำหรับ chat logging เพื่อลดโอกาสค้างก่อน response
- เพิ่ม `query_debug` ใน Vercel entry `api/chat.py`
- ผล local pipeline หลังแก้:
  - `PS5 มีเกมอะไรบ้าง` เร็วลงเหลือประมาณต่ำกว่า 1 วินาที
  - `เกมทนิฟยอดนิยมมีอะไรบ้าง` route เป็น knowledge และตอบ MOBA popular games ได้
