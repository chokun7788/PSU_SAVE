# 2026-08-30

## Latest Update - Keyboard Input Anomaly Detector and 500-case Evaluation

- สร้าง Prototype Detector แยกจาก Runtime สำหรับ `keyboard_layout_mismatch` และ `repeated_character_typo`
- ใช้ hidden Thai/English keyboard hypothesis + character n-gram จาก clean benchmark 1,600 ข้อ โดยไม่ใช้ Alias ไล่ทีละคำ
- เพิ่ม Protected Span Guard สำหรับ URL, Email, ID, JSON, วันที่, เวลา, เบอร์โทร และ English entities
- เพิ่ม repeat detector ที่แยก accidental typo ออกจาก expressive repetition และ lexical double
- สร้าง runner ที่เลือก threshold จาก Calibration 100 ข้อ แล้วบันทึกผลรายข้อ JSONL/CSV สำหรับข้อมูลรวม 500 ข้อ
- Threshold รอบสุดท้าย: Layout `0.418411`, Repeat `0.718849`
- Regression result 400 ข้อ: Precision/Recall/F1 ของทั้ง Layout และ Repeat เท่ากับ 100%, Exact Flag/Action Accuracy 100%, ไม่มี False Positive บน no-flag controls
- เวลาเฉลี่ย `0.804 ms/ข้อความ`, P95 `1.642 ms`, สูงสุด `3.530 ms`
- Hidden preview ตรง Canonical เพียง 59.90% ของ Layout-positive ทั้งหมด จึงยืนยันว่าห้าม Auto-correct หรือส่ง candidate ไปตอบอัตโนมัติ
- ระบุ Disclosure ไว้ในรายงานแล้วว่า Test Split ถูกเปิดดูระหว่าง feature debugging ผล 100% จึงเป็น Regression Benchmark ไม่ใช่ Production Accuracy หรือ Independent Holdout
- ยังไม่ได้เชื่อม Detector เข้ากับ Web/API/Answer Pipeline; ขั้นถัดไปคือ shadow mode และสร้าง Holdout ใหม่จากข้อความจริงที่ anonymize แล้ว

## Latest Update - Keyboard Input Anomaly Ground Truth 500

- สร้าง Ground Truth สำหรับตรวจ `keyboard_layout_mismatch` และ `repeated_character_typo` จำนวน 500 ข้อ
- แบ่งเป็น Calibration 100 ข้อ และ Test 400 ข้อ
- มี Layout mismatch 240 ข้อ, repeated-character typo 200 ข้อ, ซ้อนกัน 60 ข้อ และ Hard Negative 120 ข้อ
- ครอบคลุมผิดทั้งข้อความ ผิดบางช่วง เปลี่ยนภาษากลางประโยค ไทย/อังกฤษสองทิศทาง ตัวอักษรไทย/อังกฤษเบิ้ล สระ/วรรณยุกต์เบิ้ล และข้อควบคุมที่ห้ามตรวจผิด
- สร้างไฟล์ JSONL, CSV, Summary, generator และเอกสารอธิบาย Dataset
- ตรวจแล้วว่า ID และ `observed_input` ไม่ซ้ำ จำนวนแต่ละ Family ตรงตามแผน และ CSV/JSONL มี 500 แถวเท่ากัน
- ยังไม่ได้แก้ Runtime Detector หรือเปิดใช้การแก้ข้อความอัตโนมัติ
