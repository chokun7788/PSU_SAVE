# 01 - โจทย์และเป้าหมายของ AI Chatbot

โปรเจกต์นี้คือการทำ AI Chatbot สำหรับเว็บ PSU Esports Studio - Phuket โดยบอทควรตอบคำถามจากข้อมูลในเว็บและระบบจอง เช่น:

- กฎการจอง
- วิธีจอง
- วิธีเช็คอิน
- การยกเลิก
- ค่าปรับหรือเงื่อนไขความเสียหาย
- เกมของศูนย์
- อุปกรณ์ที่ให้บริการ
- ข้อมูลการแข่งขัน
- กิจกรรม
- ข่าวสาร
- ช่องทางติดต่อ

---

## เป้าหมายหลัก

บอทควรทำสิ่งเหล่านี้ได้:

1. ตอบภาษาไทยได้ชัดเจน
2. ตอบจากข้อมูลจริง ไม่เดา
3. อ้างอิงแหล่งข้อมูลหรือ category ได้
4. ถ้าไม่พบข้อมูล ต้องบอกว่าไม่พบ
5. รองรับข้อมูลเว็บที่เปลี่ยนในอนาคต
6. Deploy ให้ผู้ใช้จริงทดลองได้
7. วัดคุณภาพคำตอบได้
8. คุม cost ได้

---

## สิ่งที่ไม่ควรทำตั้งแต่แรก

ไม่ควรเริ่มจากการ fine-tune หรือ train โมเดลให้จำข้อมูลเว็บทันที เพราะ:

- ข้อมูลเว็บเปลี่ยนแล้วต้องทำใหม่
- ใช้เวลาเยอะ
- ต้องมี dataset คุณภาพสูง
- ต้องมี GPU และความรู้ด้าน training
- อาจยังตอบผิดถ้าไม่มี retrieval
- deploy ยากกว่า

สำหรับงานนี้ ควรใช้ RAG ก่อน

---

## RAG คืออะไรในโปรเจกต์นี้

RAG ย่อมาจาก Retrieval-Augmented Generation

แปลแบบเข้าใจง่าย:

```text
เราไม่บังคับให้โมเดลจำข้อมูลทั้งหมด
แต่ให้ระบบค้นข้อมูลที่เกี่ยวข้องจากฐานข้อมูล
แล้วส่งข้อมูลนั้นให้โมเดลอ่านก่อนตอบ
```

ตัวอย่าง:

```text
ผู้ใช้ถาม:
"PS5 มีเกมอะไรบ้าง"

ระบบค้น:
chunk/category ที่เกี่ยวกับ game center และ PS5

ส่งให้ LLM:
คำถาม + ข้อมูล PS5 ที่ค้นเจอ

LLM ตอบ:
สรุปรายชื่อเกม พร้อมบอกว่ามาจากหมวดเกมของศูนย์
```

---

## ทำไม RAG เหมาะกับเว็บนี้

เพราะข้อมูลเป็นลักษณะ knowledge base:

- กฎ
- เงื่อนไข
- รายชื่อเกม
- วิธีใช้งานระบบ
- ข่าว/บทความ
- รายละเอียดบริการ

ข้อมูลแบบนี้เหมาะกับการค้นและอ้างอิง มากกว่าการเทรนให้จำ

---

## เป้าหมายภายใน 2 เดือน

ระบบที่ควรทำให้ได้:

```text
Chatbot UI
+ Backend API
+ RAG pipeline
+ Vector database
+ Curated facts
+ Citation
+ Evaluation set
+ Logging
+ Deploy
+ Cost strategy
```

ถ้าทำแบบ Local ด้วย ควรเพิ่ม:

```text
Local LLM serving
+ GPU/server sizing
+ benchmark
+ latency test
+ API fallback
```

---

## เกณฑ์ว่าระบบพร้อมใช้งานจริงหรือยัง

ถือว่าพร้อม MVP ถ้า:

- ตอบคำถามสำคัญเรื่องการจองได้ถูก
- ตอบรายชื่อเกม/อุปกรณ์ได้ถูก
- ไม่มั่วเมื่อไม่มีข้อมูล
- มี citation หรือบอก category/source ได้
- มี log คำถามและคำตอบ
- deploy ให้คนอื่นลองใช้ได้
- มีชุดคำถามทดสอบอย่างน้อย 50-100 ข้อ
