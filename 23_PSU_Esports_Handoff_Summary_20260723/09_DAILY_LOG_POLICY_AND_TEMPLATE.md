# Daily Log Policy And Template

## ชื่อไฟล์

ใช้วันที่ปัจจุบัน:

```text
YYYY-MM-DD.md
```

เช่น:

```text
2026-07-23.md
```

## เมื่อไหร่ต้องเขียน

ต้องเขียนเมื่อ:

- แก้ logic
- เพิ่ม data
- เพิ่ม/แก้ test
- เพิ่ม eval
- เปลี่ยน pipeline/routing/retrieval/LLM
- สร้าง handoff
- แก้ notebook/local chat tool
- พบปัญหาสำคัญที่ควรจำต่อ

ไม่จำเป็นต้องเขียนเมื่อ:

- ตอบคำถามทั่วไปสั้น ๆ
- อธิบายแนวคิดโดยไม่ได้แตะไฟล์
- user ถามสถานะเฉย ๆ

## หลักการเขียน

- สั้นแต่ครบ
- เขียนเป็นภาษาไทย
- บอกปัญหาและสาเหตุถ้ารู้
- บอกสิ่งที่แก้/เพิ่ม
- บอกผลทดสอบหรือผลตรวจที่สำคัญ
- บอกข้อจำกัด/สิ่งที่ยังไม่ได้ทำถ้ามี
- ไม่ต้องเขียน path ยาวทุกบรรทัด ถ้าไม่ได้จำเป็น
