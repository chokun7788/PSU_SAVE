# 01 — ต้องรู้อะไรบ้างก่อนทำ AI Chatbot นี้

ไฟล์นี้สรุปความรู้ที่ต้องมี ถ้าจะทำ AI Chatbot สำหรับเว็บ PSU Esports ให้ใช้งานได้จริง

---

## 1. พื้นฐานที่ต้องรู้

### Python

ต้องรู้พอประมาณ:

- อ่านไฟล์ `.jsonl`
- ใช้ `dict` / `list`
- เขียน function
- ใช้ virtual environment
- ติดตั้ง package ด้วย `pip`
- เรียก API
- จัดการ `.env`

ตัวอย่างที่ต้องเขียนได้:

```python
import json

with open("data/processed/all_chunks.jsonl", encoding="utf-8") as f:
    for line in f:
        item = json.loads(line)
        print(item["category"], item["text"][:100])
```

### JSONL

JSONL คือไฟล์ที่ 1 บรรทัด = 1 JSON object

เหมาะกับข้อมูล RAG เพราะ:

- อ่านทีละ record ได้
- เพิ่มข้อมูลใหม่ง่าย
- ใช้กับ pipeline ได้ง่าย

ตัวอย่าง:

```json
{"id":"chunk_001","category":"reservation","text":"ต้องจองล่วงหน้าอย่างน้อย 1 ชั่วโมง"}
{"id":"chunk_002","category":"services","text":"PS5 มีเกม TEKKEN 8"}
```
 
### API

ต้องรู้ว่า chatbot อาจต้องเรียก:

- LLM API
- Embedding API
- Backend API ของเราเอง

### Markdown

ข้อมูลสรุปและคู่มืออยู่ในไฟล์ `.md` ต้องอ่าน/แก้ได้

## 2. ความรู้ LLM ที่ต้องเข้าใจ

### LLM คืออะไร

LLM คือโมเดลภาษาที่สร้างคำตอบจาก prompt ไม่ได้รู้ข้อมูลเว็บเราเอง จึงต้องส่งข้อมูลเว็บเข้าไปเป็น context

### Context

Context คือข้อมูลที่เราดึงจากเว็บแล้วส่งให้ LLM เพื่อใช้ตอบ

ถ้า context ผิด คำตอบก็ผิด

### Hallucination

LLM อาจแต่งคำตอบเอง ดังนั้นต้องบังคับว่า:

- ตอบจาก context เท่านั้น
- ถ้าไม่มีข้อมูลให้ตอบว่าไม่พบ
- ต้องมี citation

---

## 3. ความรู้ RAG ที่ต้องเข้าใจ

RAG = Retrieval-Augmented Generation

แปลแบบง่าย:

```text
ค้นข้อมูลที่เกี่ยวข้องก่อน -> ส่งให้ LLM -> ให้ LLM ตอบจากข้อมูลนั้น
```

ส่วนประกอบ:

- Document / page / chunk
- Embedding
- Vector database
- Retriever
- Prompt
- LLM
- Citation

---

## 4. ความรู้ Embedding

Embedding คือการแปลงข้อความเป็นเวกเตอร์

ใช้เพื่อค้นข้อความที่ “ความหมายใกล้กัน”

สำหรับเว็บนี้ควรใช้ embedding ที่รองรับไทยและอังกฤษ เพราะข้อมูลมีทั้ง:

- ภาษาไทย
- ชื่อเกมภาษาอังกฤษ
- คำทับศัพท์
- รหัสกิจกรรม / tournament

ตัวเลือก:

- `multilingual-e5`
- `BGE-M3`
- OpenAI embedding
- Cohere multilingual embedding

---

## 5. ความรู้ Vector Database

Vector DB ใช้เก็บ embedding และค้น top-k chunk

เริ่มต้น:

- Chroma
- FAISS

ใช้งานจริง:

- Qdrant
- pgvector
- Weaviate

---

## 6. ความรู้ Prompt Engineering

ต้องออกแบบ prompt ให้บอท:

- ตอบภาษาไทย
- ตอบจาก context
- ไม่เดา
- บอกว่าไม่พบเมื่อข้อมูลไม่พอ
- อ้างอิง URL
- ปฏิเสธข้อมูลส่วนตัว
- ไม่บอกสถานะจอง real-time ถ้าไม่ได้เชื่อมระบบจริง

---

## 7. ความรู้เฉพาะเว็บ PSU Esports

ต้องเข้าใจหมวดข้อมูล:

| หมวด | ใช้ตอบ |
|---|---|
| `reservation` | กฎการจอง เช็คอิน ยกเลิก ค่าปรับ |
| `services` | เกม อุปกรณ์ PC/PS5/Switch/VR/Cockpit |
| `competition` | การแข่งขันและกิจกรรม |
| `news` | ข่าวของศูนย์ |
| `knowledge` | ความรู้เกี่ยวกับอีสปอร์ต |
| `contact` | ช่องทางติดต่อ |
| `policies` | privacy/cookie/security |

---

## 8. ความรู้ด้าน Evaluation

ต้องวัดว่า:

- ค้นข้อมูลถูกไหม
- ตอบตรงคำถามไหม
- ไม่ hallucinate ไหม
- อ้างอิงถูกไหม
- ถามนอกขอบเขตแล้วไม่เดาไหม
