# 14 - คำถามสำหรับคุย Requirement เรื่อง AI Chatbot

ใช้ไฟล์นี้สำหรับเตรียมคุยรายละเอียด AI Chatbot ของเว็บ PSU Esports หรือโปรเจกต์ลักษณะใกล้เคียง

วันที่เตรียม: 2026-06-29  
ใช้คุยพรุ่งนี้: 2026-06-30

---

## วิธีใช้

เริ่มจากถามชุด "ต้องถามให้ได้" ก่อน เพราะเป็นข้อมูลที่กระทบ architecture, cost, timeline และ scope โดยตรง

ถ้ามีเวลาค่อยถามชุด "ถามเพิ่มถ้ามีเวลา" เพื่อเก็บรายละเอียดสำหรับ production, UX และ maintenance

---

## 1. เป้าหมายของ Chatbot

### ต้องถามให้ได้

- อยากให้ Chatbot แก้ปัญหาอะไรเป็นหลัก
- กลุ่มผู้ใช้หลักคือใคร เช่น นักศึกษา บุคลากร บุคคลภายนอก แอดมิน
- ต้องการให้บอทตอบเรื่องอะไรบ้าง
- เรื่องไหนที่บอท "ต้องตอบได้แน่นอน"
- เรื่องไหนที่บอท "ห้ามตอบ" หรือควรส่งต่อให้คน
- ต้องการให้บอทเป็นแค่ FAQ/RAG หรือให้ทำ action ได้ด้วย เช่น จอง ยกเลิก เช็คสถานะ
- เป้าหมายความสำเร็จคืออะไร เช่น ลดงานแอดมิน ตอบเร็วขึ้น ใช้เป็น demo งานวิจัย ใช้จริงในเว็บ

### ถามเพิ่มถ้ามีเวลา

- อยากให้บุคลิกบอทเป็นทางการ เป็นกันเอง หรือเหมือนผู้ช่วยศูนย์
- ต้องการให้ตอบสั้นหรืออธิบายละเอียด
- ต้องการให้มี citation/source ทุกคำตอบไหม
- ต้องการให้บอทบอกความมั่นใจของคำตอบไหม

---

## 2. ขอบเขตความรู้ของบอท

### ต้องถามให้ได้

- ข้อมูลที่จะให้บอทใช้มาจากที่ไหนบ้าง
- ใช้เฉพาะข้อมูลจากเว็บไซต์ หรือมีเอกสารภายในด้วย
- ข้อมูลมีรูปแบบอะไร เช่น webpage, PDF, Word, Excel, database, API, Google Drive
- ข้อมูลมีขนาดประมาณเท่าไหร่
- ข้อมูลอัปเดตบ่อยแค่ไหน
- ใครเป็นเจ้าของข้อมูลและใครเป็นคนยืนยันว่าข้อมูลถูก
- ถ้าข้อมูลในเว็บกับเอกสารภายในไม่ตรงกัน ให้เชื่อแหล่งไหน
- มีข้อมูลที่เป็นความลับหรือข้อมูลส่วนบุคคลไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องการให้ระบบดึงข้อมูลเว็บอัตโนมัติทุกกี่วัน
- ต้องมีหน้า admin สำหรับอัปโหลด/แก้ knowledge base ไหม
- ต้อง version ข้อมูลไหม เช่น กฎการจองเวอร์ชันเก่า/ใหม่
- ต้องการเก็บ log ว่าคำตอบอ้างอิงจากเอกสารไหนไหม

---

## 3. ความสามารถที่ต้องการ

### ต้องถามให้ได้

- ต้องการให้ตอบได้เฉพาะข้อมูล หรือคำนวณ/ตัดสินใจบางอย่างได้ด้วย
- ต้องการคำนวณราคา ค่าปรับ วันที่ เวลา หรือ slot การจองไหม
- ต้องการให้ดูสถานะการจองจริงไหม
- ต้องการให้ Login หรือเชื่อมบัญชีผู้ใช้ไหม
- ต้องการให้บอทเรียก API ของระบบจองได้ไหม
- ต้องการให้บอททำ action ได้ไหม เช่น สร้างการจอง ยกเลิกการจอง ส่งแจ้งเตือน
- ถ้าให้บอททำ action ได้ ต้องการให้มีขั้นตอนยืนยันก่อนทำจริงไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องการให้บอทสรุปข่าว/กิจกรรมล่าสุดได้ไหม
- ต้องการให้บอทช่วยแนะนำเกมตามความสนใจไหม
- ต้องการให้บอทแนะนำขั้นตอนตามสถานะผู้ใช้ไหม เช่น ยังไม่ได้ login, login แล้ว, มี booking แล้ว
- ต้องการให้บอทตอบคำถามหลายภาษาไหม ไทย/อังกฤษ

---

## 4. Input / Output ที่ต้องรองรับ

### ต้องถามให้ได้

- ผู้ใช้จะถามเป็น Text อย่างเดียว หรือมี Image / Voice ด้วย
- ต้องการให้ผู้ใช้แนบรูปได้ไหม เช่น screenshot ปัญหาหน้าจอง
- ต้องการให้รับเสียงพูดแล้วแปลงเป็นข้อความไหม
- ต้องการให้บอทตอบเป็นข้อความอย่างเดียว หรือมีรูป ตาราง ปุ่ม ลิงก์ด้วย
- ต้องการให้มี quick buttons เช่น "วิธีจอง", "กฎการจอง", "เกม PS5"

### ถามเพิ่มถ้ามีเวลา

- ต้องการให้บอทอ่านไฟล์ PDF/Excel ที่ผู้ใช้อัปโหลดไหม
- ต้องการให้บอทตอบเป็น card หรือ step-by-step UI ไหม
- ต้องการให้มี voice output ไหม

---

## 5. API หรือ Local

### ต้องถามให้ได้

- อยากใช้ LLM ผ่าน API หรือรัน Local/Self-hosted
- มี LLM ตัวไหนในใจอยู่แล้วไหม
- ถ้าใช้ API ใช้ provider ไหนได้บ้าง เช่น OpenAI, Gemini, Claude, Typhoon
- ถ้าใช้ Local มีเครื่อง GPU หรือ server ให้ไหม
- มีข้อกำหนดว่า data ห้ามออกนอกองค์กรไหม
- ต้องการ Hybrid ไหม เช่น คำถามง่ายใช้ local คำถามยากใช้ API
- ยอมรับค่าใช้จ่ายรายเดือนได้ประมาณเท่าไหร่

### ถามเพิ่มถ้ามีเวลา

- ต้องการให้ระบบสลับ provider ได้ไหม
- ต้องการ fallback ไหมถ้า API ล่มหรือ local model ตอบไม่ได้
- มีนโยบายเรื่อง cloud/provider จากองค์กรไหม
- ต้องการทดลองหลายโมเดลแล้วเทียบผลก่อนเลือกไหม

---

## 6. Model / LLM Requirement

### ต้องถามให้ได้

- ต้องการให้ AI เก่งระดับไหน เช่น ตอบ FAQ, สรุปข้อมูล, reasoning, คำนวณ, ใช้ tool
- ต้องการ model parameter ประมาณไหน หรือมีข้อจำกัดเรื่องขนาดโมเดลไหม
- ถ้าเป็น Local ต้องการรันโมเดลขนาดประมาณ 7B, 14B, 32B หรือใหญ่กว่านั้นไหม
- ต้องการ context length ประมาณเท่าไหร่ เช่น อ่านหลายหน้าพร้อมกันไหม
- ต้องการความเร็วตอบประมาณกี่วินาที
- ยอมรับความผิดพลาดได้แค่ไหน โดยเฉพาะเรื่องกฎการจอง

### ถามเพิ่มถ้ามีเวลา

- ต้องการ fine-tune ไหม หรือเริ่มจาก RAG ก่อน
- มีชุดคำถาม-คำตอบจริงสำหรับ train/eval ไหม
- ต้องการให้บอทเรียนรู้จาก feedback ผู้ใช้ไหม
- ต้องการให้มีระบบ human review ก่อนนำคำตอบใหม่ไปใช้ไหม

---

## 7. Cloud / Server / Infrastructure

### ต้องถามให้ได้

- มี cloud หรือ server ให้ใช้อยู่แล้วไหม
- ใช้ cloud เจ้าไหนได้บ้าง เช่น AWS, Google Cloud, Azure, VPS, server มหาวิทยาลัย
- มีงบสำหรับ server รายเดือนเท่าไหร่
- ถ้ารัน Local มี GPU รุ่นอะไร VRAM เท่าไหร่
- ต้องการ deploy ที่ไหน เช่น เว็บศูนย์, server ภายใน, cloud, Docker
- ต้องการ uptime ระดับไหน เช่น ใช้งานเฉพาะเวลาทำการ หรือ 24/7
- มี domain/subdomain ให้ไหม
- มีคนดูแล server หลัง deploy ไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องใช้ Docker/Kubernetes ไหม
- มีระบบ monitoring/logging เดิมไหม
- มี backup policy ไหม
- ต้องผ่าน security review ขององค์กรไหม

---

## 8. ระบบจองและ Integration

### ต้องถามให้ได้

- Chatbot ต้องเชื่อมกับระบบจองจริงไหม
- ระบบจองมี API ให้ใช้ไหม
- API มีเอกสารหรือคนดูแลไหม
- ต้องใช้ authentication แบบไหน
- บอทต้องอ่านข้อมูลอะไรจากระบบจอง เช่น slot ว่าง รายการจอง สถานะเช็คอิน
- บอทต้องเขียนข้อมูลอะไรกลับเข้าระบบจองไหม เช่น สร้าง booking ยกเลิก booking
- ถ้าผู้ใช้ถามเรื่องข้อมูลส่วนตัว ต้องให้ login ก่อนใช่ไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องมี role แยกไหม เช่น user/admin/staff
- ต้องเก็บ audit log การกระทำของบอทไหม
- ถ้าบอททำ booking ผิด ใครรับผิดชอบและ rollback ยังไง
- ต้องมี human approval ก่อน action สำคัญไหม

---

## 9. UX / ช่องทางใช้งาน

### ต้องถามให้ได้

- Chatbot จะอยู่ตรงไหน เช่น หน้าเว็บ, LINE OA, Facebook, Discord, mobile app
- ต้องการ widget ฝังในเว็บไหม
- ต้องการให้ผู้ใช้ login ก่อนถามไหม
- ต้องการเก็บ history การสนทนาไหม
- ถ้าไม่ login ให้ chat เป็น session ชั่วคราวได้ไหม
- ต้องการให้แอดมินดูประวัติคำถามได้ไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องการปุ่ม feedback ถูก/ผิดไหม
- ต้องการให้บอทส่งต่อให้เจ้าหน้าที่ได้ไหม
- ต้องการให้มี suggestion หลังตอบไหม
- ต้องการธีม UI ตามเว็บศูนย์ไหม

---

## 10. ความปลอดภัยและนโยบาย

### ต้องถามให้ได้

- มีข้อมูลส่วนบุคคลอะไรที่บอทอาจเห็น
- ข้อมูลสนทนาเก็บได้นานแค่ไหน
- ต้องปิดบังข้อมูลส่วนตัวใน log ไหม
- มีคำถามหรือเนื้อหาที่บอทไม่ควรตอบไหม
- ต้องมี rate limit กัน spam ไหม
- ต้องมี admin approval สำหรับแก้ข้อมูลไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องทำ consent/privacy notice ไหม
- ต้องมี policy สำหรับ prompt injection ไหม
- ต้องแยก environment dev/staging/prod ไหม

---

## 11. งบประมาณและ Timeline

### ต้องถามให้ได้

- งบทั้งหมดสำหรับทำโปรเจกต์มีเท่าไหร่
- งบรายเดือนสำหรับ API/server/cloud มีเท่าไหร่
- ยอมรับค่าใช้จ่ายต่อเดือนสูงสุดเท่าไหร่
- deadline จริงคือวันไหน
- ต้อง demo กี่รอบและรอบไหนต้องมีอะไรให้เห็น
- MVP ต้องมี feature อะไรบ้าง
- feature ไหนเลื่อนไป phase 2 ได้

### ถามเพิ่มถ้ามีเวลา

- ต้องการรายงาน cost dashboard ไหม
- ต้องการเปรียบเทียบ API vs Local ก่อนตัดสินใจไหม
- มีงบซื้อ/เช่า GPU ไหม

---

## 12. Evaluation และการยอมรับงาน

### ต้องถามให้ได้

- จะวัดว่าบอทตอบดีจากอะไร
- มีชุดคำถามทดสอบอยู่แล้วไหม
- ใครเป็นคนตรวจคำตอบว่าถูกหรือผิด
- ต้องการ accuracy ประมาณเท่าไหร่
- เรื่องไหนห้ามผิดเด็ดขาด เช่น กฎการจอง ค่าปรับ เวลาเช็คอิน
- ถ้าบอทไม่มั่นใจ อยากให้ตอบแบบไหน

### ถามเพิ่มถ้ามีเวลา

- ต้องการ A/B test หลายโมเดลไหม
- ต้องการ monthly report ไหม
- ต้องเก็บ feedback จากผู้ใช้เพื่อปรับปรุงไหม

---

## 13. Maintenance หลัง Deploy

### ต้องถามให้ได้

- ใครจะดูแลข้อมูลหลัง deploy
- ใครจะดู log/feedback
- ถ้าข้อมูลเว็บเปลี่ยน ใครแจ้งและใคร update
- ต้องให้ระบบ re-scrape อัตโนมัติไหม
- ต้องมีเอกสารคู่มือ admin ไหม
- ต้องส่งมอบ source code/docker/env/template ไหม

### ถามเพิ่มถ้ามีเวลา

- ต้องมี SLA ไหม
- ต้องมีแผน rollback ไหม
- ต้องอบรมเจ้าหน้าที่ไหม

---

## 14. คำถามสรุปตอนท้ายประชุม

ใช้ตอนท้ายเพื่อ lock scope:

- ถ้าให้เลือก 3 feature ที่สำคัญที่สุดคืออะไร
- อะไรคือสิ่งที่ต้องเสร็จใน MVP
- อะไรสามารถเลื่อนไป phase 2 ได้
- ข้อมูลที่ต้องส่งให้ทีมพัฒนามีอะไรบ้าง
- ใครเป็น contact หลักสำหรับข้อมูล/API/server
- หลังประชุมนี้ action item ของแต่ละฝ่ายคืออะไร
- นัด review รอบถัดไปวันไหน

---

## 15. Shortlist คำถามสำคัญที่สุด 20 ข้อ

ถ้ามีเวลาคุยจำกัด ให้ถามชุดนี้ก่อน:

1. อยากให้ Chatbot แก้ปัญหาอะไรเป็นหลัก
2. ผู้ใช้หลักคือใคร
3. ต้องการให้บอทตอบเรื่องอะไรบ้าง
4. เรื่องไหนห้ามตอบผิดเด็ดขาด
5. ต้องการแค่ตอบข้อมูล หรือให้ทำ action เช่น จอง/ยกเลิกด้วย
6. ข้อมูลที่จะใช้มีจากที่ไหนบ้าง
7. ข้อมูลเป็นไฟล์/เว็บ/API/database แบบไหน
8. ข้อมูลอัปเดตบ่อยแค่ไหน
9. มี API ของระบบจองให้ใช้ไหม
10. ต้อง login ก่อนใช้ไหม
11. ต้องเก็บ history การสนทนาไหม
12. ต้องการ input แบบ Text/Image/Voice อะไรบ้าง
13. อยากใช้ API หรือ Local หรือ Hybrid
14. มี LLM/provider ในใจไหม
15. มี cloud/server/GPU ให้ไหม
16. งบทำระบบและงบรายเดือนเท่าไหร่
17. ต้อง deploy ที่ไหน
18. ต้องการให้ตอบเร็วประมาณกี่วินาที
19. จะวัดผลว่าบอทดีจากอะไร
20. Deadline/MVP ต้องมีอะไรบ้าง
