# Answer Format

ใช้รูปแบบนี้เวลาสร้างคำตอบ

```text
คำตอบ:
ตอบสั้น ๆ ให้ตรงคำถาม

รายละเอียด:
- ข้อ 1
- ข้อ 2
- ข้อ 3

อ้างอิง:
- [ชื่อหน้า] URL
```

ถ้าไม่มีข้อมูล:

```text
คำตอบ:
ไม่พบข้อมูลนี้ในเว็บไซต์หรือเอกสารที่ดึงมา

อ้างอิง:
- เว็บไซต์หลัก: https://esports.phuket.psu.ac.th/
- ระบบจอง: https://esports.computing.psu.ac.th/
```
