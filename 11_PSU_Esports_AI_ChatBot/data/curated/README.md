# Curated Facts

โฟลเดอร์นี้คือข้อมูลที่จัดรูปแบบเองจากเว็บ เพื่อช่วยให้ chatbot ตอบเรื่องที่เป็น fact ชัด ๆ ได้แม่นขึ้น เช่น:

- กฎการจอง
- ตารางเวลาให้บริการ
- กฎเช็คอิน/ยกเลิก
- รายชื่อเกมแยกตามอุปกรณ์
- ช่องทางติดต่อ

เหตุผลที่ต้องมี curated facts:

- ข้อมูลจากเว็บบางหน้าเป็นบทความยาว
- Google Sites มีเมนูและข้อความซ้ำปน
- คำถามแบบ "PS5 มีเกมอะไรบ้าง" ควรตอบจากรายการที่จัดไว้ ไม่ใช่ดึงบทความยาว

ไฟล์หลัก:

- `faq_facts.jsonl`

แนะนำให้นำไฟล์นี้เข้า vector index ร่วมกับ `data/processed/all_chunks.jsonl`
