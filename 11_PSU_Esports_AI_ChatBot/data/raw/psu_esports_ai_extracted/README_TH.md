# วิธีดูข้อมูลชุด PSU Esports Studio - Phuket

ไฟล์นี้คือคู่มือภาษาไทยสำหรับเปิดดูข้อมูลที่ดึงจากเว็บไซต์ศูนย์อีสปอร์ตและระบบจอง

โฟลเดอร์นี้มีข้อมูลที่ AI/crawler ดึงจาก:

- เว็บไซต์หลัก: https://esports.phuket.psu.ac.th/
- ระบบจอง: https://esports.computing.psu.ac.th/

---

## ควรเปิดไฟล์ไหนก่อน

ให้เปิดไฟล์นี้ก่อน:

- `README_TH.md` ไฟล์ที่กำลังอ่านอยู่ เป็นคู่มือภาษาไทย

ถ้าจะดูข้อมูลจริง ให้เข้าไปตามหมวด แล้วเปิดไฟล์:

- `summary.md` สำหรับอ่านสรุปเร็ว
- `extracted_text.md` สำหรับอ่านข้อความที่ดึงมาจากเว็บแบบละเอียดกว่า

ไฟล์ `.jsonl` เอาไว้ให้โปรแกรมหรือระบบ AI ใช้ต่อ ไม่เหมาะอ่านด้วยตาเท่าไฟล์ `.md`

## แปลชื่อโฟลเดอร์แต่ละหมวด

| โฟลเดอร์ | ความหมายภาษาไทย | ควรเปิดดูเมื่อ |
|---|---|---|
| `reservation` | ระบบจองและกฎการจอง | อยากดูกฎจอง วิธีจอง เวลาให้บริการ เช็คอิน ยกเลิก |
| `services` | บริการ อุปกรณ์ และเกมของศูนย์ | อยากดูว่าศูนย์มี PC, PS5, Nintendo Switch, VR, Cockpit และเกมอะไร |
| `competition` | การแข่งขันและกิจกรรมอีสปอร์ต | อยากดูข้อมูลการแข่งขัน เช่น RoV, Valorant, Tekken, CS2 |
| `training` | การอบรมและกิจกรรมเรียนรู้ | อยากดูกิจกรรมอบรม/หลักสูตร/กิจกรรมเสริม |
| `news` | ข่าวสารและความเคลื่อนไหว | อยากดูข่าวทั้งหมดของศูนย์เรียงตามกิจกรรม/เดือน/ปี |
| `knowledge` | บทความความรู้เกี่ยวกับอีสปอร์ตและเกม | อยากอ่านความรู้ เช่น Esports คืออะไร ประเภทเกม อาชีพ เกมยอดนิยม |
| `about_us` | ข้อมูลเกี่ยวกับศูนย์ | อยากดูข้อมูลศูนย์ สมาชิก แกลเลอรี ดาวน์โหลด |
| `contact` | ข้อมูลติดต่อ | อยากดูเบอร์โทร อีเมล Facebook ที่อยู่ |
| `policies` | นโยบายความปลอดภัย คุกกี้ และความเป็นส่วนตัว | อยากดู Privacy Policy, Cookie Policy, Website Security |
| `main` | หน้าหลักของเว็บไซต์ | อยากดูข้อความหน้าหลัก/ภาพรวมศูนย์ |
| `other` | ข้อมูลอื่น ๆ | ข้อมูลที่ไม่เข้าหมวดหลัก |

## ในแต่ละโฟลเดอร์มีไฟล์อะไร

ตัวอย่างเช่นในโฟลเดอร์ `reservation` จะมีไฟล์แบบนี้:

```text
reservation/
  summary.md
  extracted_text.md
  pages.jsonl
  chunks.jsonl
```

ความหมายของแต่ละไฟล์:

| ไฟล์ | ความหมาย | เหมาะกับใคร |
|---|---|---|
| `summary.md` | สรุปข้อมูลของหมวดนั้นแบบอ่านง่าย | คนอ่านทั่วไป |
| `extracted_text.md` | ข้อความที่ดึงมาจากเว็บแบบละเอียดกว่า | คนที่อยากอ่านข้อมูลเต็ม |
| `pages.jsonl` | ข้อมูลระดับหน้าเว็บ 1 บรรทัดต่อ 1 หน้า | นักพัฒนา/เอาไปประมวลผล |
| `chunks.jsonl` | ข้อมูลที่แบ่งเป็นชิ้นเล็ก ๆ สำหรับทำ RAG/embedding | นักพัฒนา/ทำ chatbot |

## ถ้าจะเอาไปทำ Chatbot หรือ RAG

ใช้ไฟล์นี้:

- `chunks.jsonl` ในแต่ละหมวด

หรือถ้าต้องการรวมทุกหมวด ให้ใช้ชุดก่อนหน้าที่อยู่ใน:

- `../psu_esports_jsonl/chunks/all_chunks.jsonl`

แต่ถ้าเพิ่งเริ่ม แนะนำให้ใช้แยกหมวดก่อน เช่น:

- ใช้ `reservation/chunks.jsonl` ทำ chatbot ตอบเรื่องการจอง
- ใช้ `services/chunks.jsonl` ทำ chatbot ตอบเรื่องเกม/อุปกรณ์
- ใช้ `competition/chunks.jsonl` ทำ chatbot ตอบเรื่องการแข่งขัน

## สรุปสั้นที่สุด

ถ้าจะอ่านด้วยตา:

1. เปิด `README_TH.md`
2. เข้าโฟลเดอร์หมวดที่สนใจ
3. เปิด `summary.md`
4. ถ้าอยากละเอียดขึ้น เปิด `extracted_text.md`

ถ้าจะให้ AI ใช้ต่อ:

1. ใช้ `chunks.jsonl`
2. ใช้ field `category`, `subcategory`, `tags`, `title`, `url`, `text`
3. เอา `text` ไปทำ embedding หรือใส่ RAG
