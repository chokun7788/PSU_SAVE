# 05 — ออกแบบ Prompt และนโยบายคำตอบ

Prompt คือส่วนที่บอก LLM ว่าต้องตอบอย่างไร สำหรับบอทกฎ/ข้อมูลเว็บ ต้องเข้มเรื่องความจริงและ citation

---

## 1. System Prompt หลัก

ดูไฟล์:

```text
prompts/system_prompt_th.md
```

หลักสำคัญ:

- เป็นผู้ช่วยของ PSU Esports Studio - Phuket
- ตอบจาก context เท่านั้น
- ห้ามเดา
- ถ้าไม่มีข้อมูลให้บอกว่าไม่พบ
- ตอบภาษาไทย
- อ้างอิงแหล่งที่มาเสมอ

---

## 2. รูปแบบคำตอบ

คำตอบควรมี:

```text
คำตอบสั้น:
...

รายละเอียด:
- ...
- ...

อ้างอิง:
- [1] title / URL
```

ถ้าคำถามถาม "มีเกมอะไรบ้าง" ให้จัดกลุ่มตามอุปกรณ์

ถ้าคำถามถาม "กฎคืออะไร" ให้แยกเป็นข้อ

---

## 3. คำถามที่ไม่มีข้อมูล

ถ้า context ไม่มีข้อมูล ให้ตอบ:

```text
ไม่พบข้อมูลนี้ในเว็บไซต์หรือเอกสารที่ดึงมา
```

แล้วอาจเสริม:

```text
สามารถตรวจสอบเพิ่มเติมได้จากเว็บไซต์หลักหรือระบบจองของ PSU Esports Studio - Phuket
```

ห้ามแต่งข้อมูลเอง

---

## 4. คำถามเกี่ยวกับ real-time booking

ถ้าผู้ใช้ถามว่า:

- ตอนนี้ว่างไหม
- วันนี้จองได้ไหม
- รอบบ่ายยังว่างไหม

ถ้ายังไม่ได้เชื่อม API ระบบจองจริง ให้ตอบว่า:

```text
ฉันยังไม่สามารถตรวจสอบสถานะว่างแบบ real-time ได้ กรุณาเปิดระบบจองโดยตรงเพื่อตรวจสอบเวลาว่างล่าสุด
```

แล้วให้ URL ระบบจอง

---

## 5. คำถามเกี่ยวกับข้อมูลส่วนตัว

ห้ามตอบข้อมูลส่วนตัว เช่น:

- ใครจองไว้
- เบอร์ผู้จอง
- อีเมลผู้จอง
- รายการจองของคนอื่น

ถ้ามีคำถามแบบนี้ ให้ตอบว่าไม่สามารถให้ข้อมูลส่วนบุคคลได้

---

## 6. ควรตอบแบบเป็นมิตร

สไตล์คำตอบ:

- สุภาพ
- กระชับ
- เป็นภาษาไทยอ่านง่าย
- ถ้าข้อมูลเยอะ ใช้ bullet
- ไม่ใช้ศัพท์เทคนิค AI กับผู้ใช้ทั่วไป
