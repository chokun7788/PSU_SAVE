# วิธีแก้ไขข้อมูลเดิม

## เริ่มใช้งาน

เปิด `Open-Owner-Content.cmd` ในโฟลเดอร์ระบบ แล้วเลือก **แก้ไขข้อมูลเดิม**

1. เลือกหมวดและค้นหาชื่อรายการเดิม กด **✎ แก้ไข…**
2. แก้เฉพาะช่องที่เปลี่ยน **คงรหัสรายการเดิม** เพราะเกม ราคา อุปกรณ์ และกฎอาจเชื่อมถึงรหัสนี้
3. ใส่เหตุผล เช่น “ปรับราคาตามประกาศวันที่…” เพื่อช่วยตรวจย้อนหลัง
4. กด **ดูสิ่งที่เปลี่ยนก่อนบันทึก** จะเห็นค่าก่อนและหลัง ถ้ามีฉบับเผยแพร่แล้วจะเทียบกับฉบับที่แชทใช้อยู่
5. ตรวจข้อมูลและคำแปลตามจริง แล้วกด **บันทึกเป็นฉบับร่างใหม่**
6. ตรวจทานและอนุมัติร่างนี้ จากนั้น **เผยแพร่รายการนี้** เมื่อถึงวันที่มีผล

การบันทึกหรืออนุมัติร่างอย่างเดียวยังไม่เปลี่ยนคำตอบจากข้อมูลที่เผยแพร่แล้ว ฉบับเก่าเก็บไว้ในประวัติ ไม่ถูกเขียนทับ การเปิดประวัติเป็นการอ่านอย่างเดียว ไม่ใช่การคืนค่าหรือเผยแพร่ย้อนหลัง

## ตัวอย่างแต่ละหมวด

### ราคาเปลี่ยนจาก 35 เป็น 40 บาท

เลือกหมวดอัตราค่าบริการ แล้วเลือกแถวของบริการ กลุ่มผู้ใช้ และระยะเวลาที่ต้องการแก้ กรอก **40** ในช่องจำนวนเงิน หน้าฟอร์มใช้หน่วยบาท ระบบแปลงเป็นหน่วยย่อยภายในเอง ไม่ต้องกรอก 4000 ตรวจสกุลเงิน หน่วยเวลา และเงื่อนไขว่าเป็นแถวที่ถูกต้องก่อนเผยแพร่

ราคามีหลายกลุ่มผู้ใช้หรือหลายบริการ ให้แก้แต่ละรายการที่ประกาศเปลี่ยนจริง การแก้หนึ่งแถวไม่ได้เปลี่ยนทุกแถวโดยอัตโนมัติ

### รายละเอียดเกมเปลี่ยน

เลือกหมวดเกม แล้วแก้ชื่อ คำอธิบาย วิธีเล่น หรือแพลตฟอร์มตามจริง ถ้าเปลี่ยนปุ่มควบคุมให้แก้หมวดชุดควบคุมของเกมและแพลตฟอร์มนั้น ถ้าเปลี่ยนว่าศูนย์มีเกมนี้ให้เล่นบนบริการใด ให้แก้รายการเชื่อมเกมกับบริการด้วย ไม่ต้องสร้างเกมซ้ำเพียงเพื่อแก้รายละเอียด

### กฎเปลี่ยน

กฎใช้บริการศูนย์อยู่หมวดนโยบาย ส่วนกฎรายการแข่งขันอยู่หมวดกฎการแข่งขัน เลือกรายการและหัวข้อให้ตรงกับประกาศ แล้วแก้เฉพาะข้อความ ขอบเขต ข้อยกเว้น และวันที่มีผลที่ยืนยันได้ ห้ามนำกฎของเกมหรือการแข่งขันหนึ่งไปแทนอีกเกมเพียงเพราะชื่อคล้ายกัน

## วันที่มีผลและภาษาอังกฤษ

- หากฉบับใหม่เริ่มใช้ในอนาคต และรายการเดิมมีผลอยู่ตอนนี้ ระบบจะกันการเผยแพร่ที่ทำให้ฉบับเดิมหายไปก่อนเวลา ให้เก็บฉบับใหม่เป็นร่าง แล้วเผยแพร่เมื่อถึงวันที่มีผล **ยังไม่มีการตั้งเวลาเผยแพร่อัตโนมัติ**
- อย่าเปลี่ยนวันสิ้นสุดฉบับเดิมหรือวันเริ่มใหม่โดยเดา กรอกตามประกาศของเจ้าของ
- เมื่อเนื้อหาเปลี่ยน ต้องตรวจคำแปลใหม่ ถ้ายังไม่ได้ตรวจ อย่าติ๊กยืนยันว่าเจ้าของตรวจภาษาอังกฤษแล้ว
- การตรวจทานกับการเผยแพร่เป็นคนละขั้น ตรวจสถานะฉบับที่แชทใช้อยู่เหนือฟอร์มหลังเผยแพร่

## ดูประวัติและข้อจำกัด

กด **ดูประวัติฉบับเก่า** แล้วเลือกหมายเลขฉบับ จะเห็นข้อมูล ผู้แก้ เวลาไทย และเหตุผลที่บันทึกไว้ หน้าประวัติแสดงล่าสุด 50 ฉบับ พร้อมจำนวนฉบับทั้งหมด ฉบับเก่ายังเก็บในฐานข้อมูล

ถ้าเปิดค้างไว้แล้วมีคนแก้รายการเดียวกัน ระบบจะปฏิเสธการบันทึกจากฉบับเก่า ให้โหลดรายการล่าสุดก่อน เพื่อไม่ทับการแก้ไขของคนอื่น

การถอนรายการ การแก้หลายรายการพร้อมกัน การคืนฉบับเก่าจากหน้าจอ และการตั้งเวลาอัตโนมัติเป็นคนละความสามารถกับการแก้รายการเดิมในหน้านี้
