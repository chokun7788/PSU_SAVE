•    Triangle: โต้ตอบ / สำรวจ - ใช้สำหรับเปิดประตู เก็บไอเทมวัตถุดิบตามฉาก แทรกตัวเข้าช่องแคบ หรือใช้จับศัตรูจากทางด้านหลัง
