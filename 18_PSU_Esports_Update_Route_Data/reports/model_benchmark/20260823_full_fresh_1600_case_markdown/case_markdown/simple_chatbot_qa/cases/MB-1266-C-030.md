•    W / A / S / D: เคลื่อนที่ - W เดินหน้า, A ไปซ้าย, S ถอยหลัง, D ไปขวา

•    M: เปิดแผนที่ - เปิด/ปิดแผนที่
•    Tab: ดูตารางคะแนน - กดค้างเพื่อดู scoreboard
