````text
League of Legends มีข้อมูลปุ่มควบคุมดังนี้:
PC
•    Right Mouse Button: เดิน / โจมตีเป้าหมาย - คลิกขวาเพื่อเดินหรือสั่งโจมตีเป้าหมาย
•    Q / W / E / R: ใช้สกิล - ปุ่มสกิลหลักของ champion
•    Shift + Q / W / E / R: ใช้สกิลแบบ quick cast - ค่า default ที่แหล่งอ้างอิงระบุว่า Shift+Q/W/E/R ใช้ quick cast
•    Alt + Q / W / E / R: ใช้สกิลใส่ตัวเอง - ใช้ self-cast กับสกิลที่สามารถกดใส่ตัวเองได้
•    D / F: ใช้ Summoner Spell - ปุ่ม Summoner Spell สองช่อง
•    1 / 2 / 3 / 4 / 5 / 6 / 7: ใช้ไอเทมหรือ trinket - ปุ่มช่องไอเทมและ trinket ตามการตั้งค่าในเกม
•    B: กลับฐาน - เริ่ม Recall กลับฐาน
•    Spacebar: ล็อก/ดึงกล้องกลับมาตัวเอง - กดค้างเพื่อให้กล้องตาม champion ตัวเอง
•    Y: สลับล็อกกล้อง - สลับกล้องล็อก/ไม่ล็อก
•    F1 / F2 / F3 / F4 / F5: เลื่อนกล้องไปหาเพื่อนร่วมทีม - ใช้ดูตำแหน่งเพื่อนร่วมทีมตามลำดับ
•    Tab: ดู scoreboard - กดค้างเพื่อดูสถานะทีม/ศัตรู
แหล่งข้อมูล: https://dignitas.gg/articles/blogs/Unknown/8721/improving-inputs-effective-keybinds-for-lol
````
