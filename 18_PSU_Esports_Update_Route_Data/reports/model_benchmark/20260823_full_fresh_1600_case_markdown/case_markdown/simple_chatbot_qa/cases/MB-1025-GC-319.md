•    R (Right Stick): มุมกล้อง - หมุนเพื่อกวาดสายตาและควบคุมทิศทางมุมกล้อง
•    R3 (Click Right Stick): ไฟฉาย - กดคลิกลงไปตรง ๆ เพื่อเปิดหรือปิดไฟฉายในพื้นที่มืด (และใช้เขย่าจอยเมื่อไฟฉายดับ)

•    L2: เล็งเป้า (กดค้าง) - กดค้างไว้เพื่อยกอาวุธปืนหรือไอเทมขว้างขึ้นมาเตรียมเล็งยิง
•    R1: สลับอาวุธด่วน / โหมดฟังเสียง (กดค้าง) - แตะเพื่อสลับอาวุธล่าสุด หรือกดค้างเพื่อเข้าสู่โหมดฟังเสียงจับตำแหน่งศัตรูทะลุกำแพง
•    R2: รีโหลด / ใช้ไอเทม (กดค้าง) / ยิงปืน (ขณะเล็ง) - กดเพื่อรีโหลดกระสุน หรือกดค้างเพื่อใช้ไอเทมรักษา แต่ถ้ากดตอนเล็งปืนอยู่จะเป็นการเหนี่ยวไกยิง
•    Triangle: โต้ตอบ / สำรวจ / เก็บของ - ใช้เปิดประตู เก็บวัตถุดิบ คราฟต์ของ สำรวจสิ่งแวดล้อม หรือช่วยเพื่อนร่วมทาง
•    Circle: ย่อตัว / หมอบ - กดเพื่อย่อตัวลงต่ำสำหรับย่องเงียบ (Stealth) หลบสายตาและลดเสียงฝีเท้า
•    Square: โจมตีประชิด / สลับฝั่งมุมกล้อง (ขณะเล็ง) - กดเพื่อต่อยหรือหวดอาวุธประชิด แต่ถ้ากดตอนเล็งปืนจะเป็นการสลับมุมกล้องข้ามไหล่ซ้าย-ขวา
•    Cross: กระโดด / ปีนป่าย / ซูมสโคป (ขณะเล็ง) - ใช้กระโดดหรือปีนข้ามสิ่งกีดขวาง แต่ถ้ากดตอนเล็งปืนสไนเปอร์จะเป็นการเปิดส่องกล้องซูม
•    D-Pad (Up / Down / Left / Right): แผงเลือกอาวุธกากบาท - กดปุ่มทิศทางเพื่อเปิดหน้าต่างวงกลมกากบาทสำหรับเลือกเปลี่ยนอาวุธปืนหรือระเบิด
•    Touch Pad: กระเป๋าเป้ / เมนูคราฟต์ของ - เปิดหน้าต่างกระเป๋าหลังเพื่อตรวจสอบไอเทม อัปเกรดตัวละคร หรือคราฟต์ระเบิด/มีดพก
•    Options: หยุดเกม - หยุดหน้าจอเกมชั่วคราวเพื่อตั้งค่าระบบหรือออกจากเกม
