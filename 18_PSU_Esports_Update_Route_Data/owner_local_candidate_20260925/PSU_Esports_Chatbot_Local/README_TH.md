# PSU Esports Chatbot: Local Owner Package

ชุดนี้คือหน้าเว็บ Chatbot สำหรับเปิดใช้บนเครื่องของผู้ดูแล โดยข้อมูลคำถามและประวัติการใช้งานจะอยู่ในเครื่องนี้ ไม่ได้เรียก Cloud Chatbot API และไม่เปิดรับการเชื่อมต่อจากเครื่องอื่น

เวอร์ชัน `2026.09.25-owner-review-candidate` เป็นชุดให้เจ้าของทดลองและตรวจคำตอบ ยังไม่ควรประกาศเป็นระบบ Production จนกว่าจะยืนยันนโยบายบุคคลภายนอก/อาหาร ตรวจคำแปลอังกฤษที่ค้าง และทดสอบภาระใช้งานพร้อมกัน

## ก่อนเริ่มครั้งแรก

1. ติดตั้ง Python 3.11 หรือใหม่กว่า โดยเปิดตัวเลือก **Add Python to PATH** ระหว่างติดตั้ง
2. ติดตั้ง Ollama จาก https://ollama.com/download
3. เชื่อมต่ออินเทอร์เน็ตชั่วคราว แล้วดับเบิลคลิก `Open-PSU-Esports-Chatbot.cmd`
4. ครั้งแรกไฟล์นี้จะดาวน์โหลด Local Model และ RAG embedding model ให้อัตโนมัติ แล้วเปิดหน้าเว็บเอง

การดาวน์โหลดในข้อ 3 เป็นครั้งแรกครั้งเดียว หลังจากนั้นการตอบ Chatbot ใช้โมเดลในเครื่อง ไม่ใช่ Chatbot API ภายนอก

## วิธีเปิดใช้งาน

1. ดับเบิลคลิก `Open-PSU-Esports-Chatbot.cmd` เพียงไฟล์เดียว
2. เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:8080/`
3. เก็บหน้าต่าง PowerShell ที่เปิดอยู่ไว้ตลอดเวลาที่ใช้งาน Chatbot
4. ระบบจะเปิด Booking Dashboard ภายในเครื่องที่ `http://127.0.0.1:8091/` ให้อัตโนมัติ เพื่อให้คำถาม `ตอนนี้เปิดไหม` และ `Slot ไหนว่าง` อ่านสถานะสดได้

ตัวอย่างคำถามสถานะ Slot แบบเจาะจง:

- `PC Zone ว่างอะไรบ้างช่วง 15:00-16:00`
- `PC2 ว่างไหม` หรือ `PC #02 ว่างไหม` (หากไม่ระบุวันและเวลา ระบบตรวจเวลาปัจจุบัน)
- `PC3 ตอนบ่ายโมงว่างไหม` จะหมายถึง Slot `13:00-14:00`; รองรับ `บ่ายโมงครึ่ง`, `บ่ายสอง` และ `บ่ายโมงถึงบ่ายสองโมง`
- `PC3 พรุ่งนี้บ่ายโมงว่างไหม` สำหรับ Slot ล่วงหน้า และ `PC3 เมื่อวานบ่ายโมงเคยถูกจองไหม` สำหรับดูประวัติ
- `Cockpit ว่างให้เล่นไหม`, `PlayStation ว่างไหม`, `VR ว่างไหม`, `Nintendo Switch ว่างไหม`
- `PC กับ VR ว่างไหม` หรือ `Cockpit, PlayStation and Nintendo available?`
- `PC #02 ว่างไหม 13:00-14:00`
- `PS5 ว่างอะไรบ้างพรุ่งนี้ 13:00-14:00`
- `Which PS5 stations are free tomorrow from 13:00 to 14:00?`
- `Is PC2 free?` (checks the current time)
- `Is PC #02 free from 13:00 to 14:00?`

การตอบช่วงเวลา เช่น `13:00-14:00` จะนับว่าเครื่องว่างก็ต่อเมื่อว่างตลอดทั้งช่วงเท่านั้น
เมื่อถามช่วงเวลาที่ผ่านไปแล้ว ระบบจะรายงานจากประวัติ Slot ว่า `ถูกจอง` หรือ `ไม่มีรายการจอง` แทนการกล่าวว่า Slot นั้นยังจองได้ในปัจจุบัน
คำถามเครื่องเดียว เช่น `PC2 ว่างไหม`, `PS5 #01 ว่างไหม` หรือ `Cockpit #02 ว่างไหม` จะตอบเฉพาะเครื่องนั้น; คำถามโซน เช่น `PC Zone ว่างไหม`, `VR ว่างไหม` หรือ `Nintendo ว่างไหม` จะสรุปจำนวนว่างของโซนนั้น และจะแสดงรายชื่อเมื่อถามว่า `มีอะไรว่างบ้าง` หรือ `Which stations are free?` หากถามหลายโซนในคำถามเดียว ระบบจะแยกคำตอบตามโซนที่ระบุ
4. เมื่อต้องการปิดระบบ ให้กด `Ctrl + C` ที่หน้าต่าง PowerShell นั้น

หน้าเว็บรองรับ Auto / ไทย / English และใช้ Semantic RAG กับ Local LLM เพื่อช่วยเข้าใจคำถามที่เขียนได้หลายรูปแบบ

## Session และประวัติสนทนา

- ทุกครั้งที่เปิดหรือ refresh หน้าเว็บ ระบบจะเริ่ม Session ใหม่และหน้าแชตจะแสดงว่าง
- ข้อความและคำตอบของทุก Session ถูกเก็บถาวรใน SQLite และ JSONL เพื่อให้ผู้ดูแลดูย้อนหลังได้ทั้งหมด
- ปุ่ม `ล้าง / Clear` เริ่ม Session ใหม่ แต่ไม่ลบ log เดิมของผู้ดูแล
- เปิด `View-Chat-Logs.cmd` เพื่อสร้างรายงานทุก Session และทุกประวัติการคุยใน browser

## ข้อมูลและความเป็นส่วนตัว

- ฐานความรู้, vector index, Local LLM และประวัติสนทนาอยู่ในเครื่องนี้
- Chat log จะอยู่ที่ `data\logs\` และ session history อยู่ใน `data\logs\chat_history.sqlite3`
- ระบบบันทึก Session ID, คำถาม, คำตอบ, เวลา, route, mode, latency, ภาษา และแหล่งอ้างอิงของแต่ละคำตอบ
- ห้ามส่งโฟลเดอร์ `data\logs\` ให้บุคคลอื่น เพราะอาจมีข้อความที่ผู้ใช้พิมพ์ไว้
- คำตอบความรู้ทั่วไปใช้ข้อมูล release ที่แพ็กมาด้วย; URL ท้ายคำตอบเป็นแหล่งอ้างอิง ไม่ใช่การดึงหน้าเว็บสดทุกครั้ง
- ข้อยกเว้นคือคำถามสถานะเปิด-ปิดหรือ Slot จอง: ระบบอ่านข้อมูลสดจาก WordPress CSV ผ่าน Booking Dashboard ในเครื่อง หากดึงไม่สำเร็จจะไม่อ้างว่ารู้สถานะสด

## การแก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| ขึ้นว่าไม่พบ Python | ติดตั้ง Python แล้วปิด/เปิด PowerShell ใหม่ |
| ขึ้นว่าไม่พบ Ollama หรือ model | เปิด `Setup-Local-Models.cmd` อีกครั้ง |
| เปิดเว็บไม่ได้ | ตรวจว่าหน้าต่าง Start ยังเปิดอยู่ แล้วเข้า `http://127.0.0.1:8080/` ด้วยตนเอง |
| Port 8080 ถูกใช้งาน | เปิด PowerShell ในโฟลเดอร์นี้ แล้วใช้ `./Start-PSU-Esports-Chatbot.ps1 -Port 8090 -OpenBrowser` |
| คำตอบ Slot สดช้า/ตอบว่ายืนยันไม่ได้ | ตรวจว่าหน้าต่าง Start ยังเปิดอยู่และเข้า `http://127.0.0.1:8091/` ได้; ระบบจะไม่เอาข้อมูลตัวอย่างหรือตารางเก่ามาอ้างว่าเป็นสถานะสด |
| คำตอบช้า | รอให้ Local Model warm up ในคำถามแรก และหลีกเลี่ยงการเปิดหลายหน้าต่างพร้อมกัน |

## ข้อควรรู้

- ชุดนี้ใช้ข้อมูล release ที่แพ็กมาด้วย ไม่อัปเดตข้อมูล WordPress/Facebook แบบ real-time
- การเพิ่มข้อมูลใหม่ต้องผ่าน workflow content/review แล้ว rebuild structured projection และ RAG index ก่อนแทนที่ชุดนี้
- Check Slot แบบอ่านอย่างเดียวรวมอยู่แล้ว: Chatbot อ่านเฉพาะสถานะเปิด-ปิดและจำนวน Slot ว่าง/ถูกจองจาก Booking Dashboard ที่ดึง WordPress CSV สด โดยไม่รับชื่อผู้จอง รหัสนัดหมาย อีเมล หรือเบอร์โทรเข้า Chatbot
- ชุดนี้ยังไม่สร้าง Booking, Hold Slot, ยกเลิกการจอง หรือยืนยันการจ่ายเงิน เพราะงานเหล่านี้ต้องใช้ WordPress write API และผู้ให้บริการชำระเงินจริงก่อน
- อ่านรายละเอียดการใช้งานและนโยบายข้อมูลที่ `LOCAL_OPERATION_AND_DATA_POLICY_TH.md` และขอบเขต feature ที่ `OWNER_HANDOFF_AND_SCOPE_TH.md`
