# User Quality Audit Rubric

คะแนนเต็ม 10 ใช้ประเมินว่า ถ้าเป็นผู้ใช้จริงถามคำถามนั้นแล้วได้คำตอบนี้ จะใช้งานได้ดีแค่ไหน

| เกณฑ์ | คะแนน | ความหมาย |
|---|---:|---|
| correctness | 4.0 | ตอบถูกตามข้อมูลที่ควรใช้ ไม่สลับ domain ไม่มั่วข้อมูล และไม่ตอบขัดกับ expected_support |
| relevance | 2.0 | ตอบตรงคำถามก่อน ไม่ตอบกว้างเกิน ไม่ลาก catalog หรือ policy อื่นมาแทนสิ่งที่ถาม |
| evidence | 1.5 | มีแหล่งข้อมูล/section/source id ชัดเจน และ source สอดคล้องกับคำตอบ |
| completeness | 1.5 | รายละเอียดพอใช้จริง ครอบคลุมสิ่งที่ user ต้องการ เช่น จำนวน เวลา ปุ่ม ขั้นตอน หรือข้อจำกัด |
| clarity | 1.0 | อ่านง่าย กระชับ จัด format ดี ไม่ยาวเกินสำหรับคำถามเฉพาะ และไม่ทำให้ user งง |

ระดับคะแนน:

•    8.5-10 = good: ใช้ได้ดี
•    7.0-8.49 = usable: ใช้ได้แต่ควรปรับ
•    5.0-6.99 = needs_review: ผู้ใช้มีโอกาสสับสนหรือไม่ได้คำตอบครบ
•    0-4.99 = bad: ตอบผิดทาง/ไม่ตอบคำถาม/ใช้งานจริงมีปัญหาชัดเจน

หมายเหตุ: audit รอบนี้เป็น heuristic user-review pass สำหรับไล่ปัญหา 400 ข้อให้เร็ว ไม่ใช่ human ground truth ขั้นสุดท้าย
