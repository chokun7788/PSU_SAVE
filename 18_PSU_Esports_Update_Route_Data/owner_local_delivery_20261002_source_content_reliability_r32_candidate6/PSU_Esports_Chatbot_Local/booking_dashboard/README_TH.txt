PSU Booking Dashboard v22 Admin Edit Fix

แก้ใน v22
- แก้ปุ่ม "แก้ / Edit" ในหน้า admin.html ให้กดได้แน่นอน
- ใช้ event delegation ทำให้ปุ่มยังทำงานแม้รายการวันที่ถูก render ใหม่
- กดแก้แล้วจะโหลดวันที่นั้นกลับเข้า form ซ้ายมือ
- เพิ่ม feedback ว่าโหลดวันที่มาแก้แล้ว
- หน้า Admin มีปุ่มภาษา TH/EN ชัดเจน
- หน้า User ยังไม่มีลิงก์เข้า Admin
- admin.html ยังเข้าได้เองที่ http://127.0.0.1:8080/admin.html

วิธีเช็คปุ่มแก้
1) เข้า http://127.0.0.1:8080/admin.html
2) เห็นรายการวันที่ด้านขวา
3) กดปุ่ม แก้/Edit
4) วันที่และค่าเปิด/ปิดจะถูกใส่กลับมาที่ form ซ้ายมือ

Logic เดิมยังอยู่
- time = เวลาเริ่มจองจริง
- day = วันที่เท่านั้น
- no show = ล็อก slot / จองไม่ได้
- cancel = เปิด slot ให้ว่าง
- timestamp = เวลาไทย UTC+7
- weekly auto schedule เหมือนเดิม
